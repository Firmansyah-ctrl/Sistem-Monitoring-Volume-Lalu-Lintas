# Sistem Monitoring Volume Lalu Lintas Per Lima Menit

Sistem Monitoring Volume Lalu Lintas Per Lima Menit merupakan aplikasi berbasis web yang dirancang untuk membantu proses pencatatan, pengolahan, dan pemantauan volume kendaraan berdasarkan interval waktu lima menit.

## Fitur Utama

- Pencatatan volume lalu lintas per interval lima menit.
- Pengelolaan dan pemantauan data kendaraan.
- Sinkronisasi waktu CCTV untuk mendukung proses audit.
- Pengolahan data hasil pemeriksaan.
- Ekspor data ke format Excel.

## Teknologi

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- JSZip
- SheetJS (XLSX)

## Menjalankan Aplikasi

1. Clone atau unduh repository ini.
2. Buka file `audit_kamera_lite.html` menggunakan browser.
3. Pastikan koneksi internet tersedia untuk memuat library eksternal yang digunakan.

## Catatan

Aplikasi ini dikembangkan sebagai solusi pendukung proses monitoring dan audit volume lalu lintas. Data operasional dan dokumentasi internal perusahaan tidak disertakan dalam repository publikasi.
